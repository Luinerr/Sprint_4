Описание покрытия тестами
1. Добавление новых книг
- Проверка добавления книг с корректной длиной названия.
- Проверка добавления разного количества книг: от 0 до 1000.
- Проверка отклонения названий с недопустимой длиной: пустых, превышающих установленное ограничение.
2. Присвоение жанров книгам
- Проверка присвоения существующей книге допустимого жанра.
- Проверка отклонения несуществующего жанра.
- Проверка невозможности присвоения жанра книге, отсутствующей в коллекции.
3. Получение жанра книги
- Проверка получения жанра книги с установленным жанром.
- Проверка получения пустого значения для книги без установленного жанра.
- Проверка получения пустого значения при обращении к несуществующей книге.
4. Получение списка книг определённого жанра
- Проверка получения списка книг с заданным жанром.
- Проверка работы с пустой коллекцией.
- Проверка обработки несуществующего жанра.
5. Получение книг, подходящих для детей
- Проверка включения книг с разрешёнными жанрами.
- Проверка исключения книг с жанрами, не подходящими для детей.
- Проверка работы с пустой коллекцией и коллекцией без подходящих книг.
6. Получение полного списка книг и жанров
- Проверка получения словаря книг с присвоенными жанрами.
7. Добавление книг в избранное
- Проверка добавления существующей книги.
- Проверка невозможности добавления книги, отсутствующей в коллекции.
- Проверка защиты от повторного добавления одной книги.
- Проверка массового добавления книг в избранное — от 10 до 1000 элементов.
8. Удаление книг из избранного
- Проверка удаления существующей книги.
- Проверка сохранения списка избранного при попытке удалить отсутствующую в нём книгу.
9. Получение списка избранных книг
- Проверка корректности возвращаемого списка.
- Проверка работы с разным количеством избранных книг: от 0 до 1000.
